# Round seven — the brief every reviewer was given

This round tests the documentation, not the compiler. Six earlier rounds each
ended with about ninety-five things the reviewers had to guess. Milestone 35
rewrote the documentation to answer them. This round measures whether it did.

**Read only:** everything under `docs/` except `docs/QUESTIONS.md`, and
everything under `examples/` (the docs link to it). Nothing else: not the
compiler source, not `tests/`, not `corpus/`, not `README.md`, not
`HISTORY.md`.

**Do not run the compiler.** Every expected output is worked out by hand from
what the docs say. A guess only counts as a guess if you could not check it.

**The number that matters** is how many things you had to guess. Record every
one, with where you looked.
