# Lume

A language with **Ruby's feel** and *Rust's speed*. This page, and the rest
of this little site, is built by a program written in Lume itself.

## Why

- no garbage collector, no runtime
- errors are values, and they say where they came from
- one canonical layout, so `lume fmt` ends the argument

Read the [guide](guide.html), or see the [notes](notes/release.html).

    fib(35) runs in 30 ms
    the same program takes 1 s in Python
